# MADN Applications Suite

This folder houses the user-facing applications developed for the **Modular Adaptive Data Node for Dynamic Value Systems (MADN)**.

## Project Structure
*   **[Web App](file:///c:/Users/ignaz/OneDrive/Documents/Projects/2026-02-15%20Sun%202055%20Modular%20Adaptive%20Data%20Node%20%28MAD%20-%20Node%29%20for%20Dynamic%20Value%20Systems/Applications/Web%20App)** - The offline-first local-hotspot web application dashboard.
    *   `frontend/` - Modern single-page application built using HTML5, Vanilla CSS, and Vanilla JavaScript, adhering to the Human-Centric Design Framework.
    *   `backend/` - Python FastAPI web server, database schemas, and SQLite state engine for local orchestration.
