## 3.5 Tools and Materials Used

To support replication, testing, and validation of the Modular Adaptive Data Node (MADN) system design, this section details the physical hardware, software frameworks, engineering tools, and mechanical fabrication materials used in constructing the prototype. The selection prioritizes open-source toolchains, off-the-shelf components, and accessible fabrication methods to align with the resource constraints of Bulawayo and Tsholotsho.

---

### 3.5.1 Hardware and Prototyping Infrastructure

The physical assembly of the MADN prototype relies on standard computing units, edge microcontrollers, customized breakout interfaces, and sensor modules:

1.  **Central Orchestrator (The Vault)**:
    *   *Raspberry Pi 4 Model B*: Powered via a Broadcom BCM2711 quad-core Cortex-A72 64-bit SoC, configured with 4GB of LPDDR4-3200 SDRAM.
    *   *High-Endurance MicroSD Card*: A 128GB Class 10 UHS-I card, chosen for time-series write endurance.
    *   *Portable Projector*: A low-power, lightweight LED projector utilized to display diagnostic dashboards to local groups in off-grid environments.
    *   *Active Cooling System*: A dual-fan heat-sink assembly designed to prevent thermal throttling under high ambient temperatures.
    *   *Power Source*: A standard 5V USB-C Power Supply Unit (PSU) for grid-connected operations, or a 5V USB power bank during grid outages.
2.  **Edge Nodes (Intelligent Core)**:
    *   *Raspberry Pi Pico W*: An RP2040 microcontroller board featuring dual ARM Cortex-M0+ cores, 264KB SRAM, 2MB of flash memory, and an onboard CYW43439 wireless interface for local Wi-Fi connectivity.
3.  **Sensor Arrays & Modules**:
    *   *Capacitive Soil Moisture Sensors*: Corrosive-resistant analog probes used to sample localized soil hydration.
    *   *DHT22 (AM2302)*: Digital temperature and humidity sensors with single-bus outputs.
    *   *HC-SR501*: Passive Infrared (PIR) motion sensors for motion detection.
    *   *HC-SR04*: Ultrasonic distance sensors used to establish virtual tripwires.
4.  **Power Management Components (Edge Tier)**:
    *   *TP4056 Charger & Step-Up Modules*: Charging controllers and step-up converters that accept a 3.7V battery input and output a boosted 5V rail.
    *   *18650 Lithium-Ion Cells*: Rechargeable cells (3.7V nominal, 2500mAh) to power edge sensing nodes.
    *   *JST-PH 2.0 Connectors*: Standard two-pin connectors for swapping battery packs in the field.
5.  **User Interface Components (Edge Tier)**:
    *   *ST7735 SPI TFT Display*: Color displays (1.8-inch or 2.4-inch) showing local node telemetry and diagnostics.
    *   *Tactile Buttons*: Momentary push-buttons configured with internal pull-up resistors for user inputs.

### 3.5.2 Software Development and Deployment Toolchain

The system's firmware, local-first databases, and network gateways are built using open-source platforms and protocols:

1.  **Operating Systems & Runtimes**:
    *   *Kali Linux (ARM64 Headless)*: Minimal Debian-based operating system running on the central Raspberry Pi 4 to maximize available CPU and RAM.
    *   *MicroPython Firmware (v1.20+)*: Microcontroller runtime environment deployed on the Pico W, optimized for memory footprint and rapid logic updates.
2.  **Telemetry and Middleware**:
    *   *Mosquitto MQTT Broker*: A lightweight broker running on the Pi 4 to orchestrator network publish/subscribe telemetry paths.
    *   *Hostapd & Dnsmasq*: Local network utilities configuring the Pi 4 as an offline wireless Access Point (AP).
    *   *PyBluez / Python SocketServer*: Daemons executing socket connection listeners for local Bluetooth (RFCOMM/SPP) payloads.
3.  **Databases & Dashboards**:
    *   *InfluxDB (v2.x)*: A time-series database engine configured to record and query sensor telemetry on the central Pi 4.
    *   *SQLite*: An ACID-compliant local database engine running POS transaction ledger writes.
    *   *Grafana (v9.x+)*: An analytics platform configured with local dashboards projected via the portable projector.
4.  **Machine Learning & Inference**:
    *   *TensorFlow Lite Runtime*: Interpreter-only library deployed on the Pi 4 to execute local watering requirement prediction models.
5.  **Development Environments**:
    *   *Thonny IDE*: MicroPython script uploading and interactive shell debugging.
    *   *VS Code*: Main script and database script environment configured with the MicroPico extension.

---

### 3.5.3 CAD, Modeling, and Simulation Software

Engineering software was used to design enclosures, lay out PCBs, and simulate operational environments:

1.  **FreeCAD (v0.20+)**: Open-source, parametric 3D computer-aided design software used to model weather-resistant, snap-fit enclosures for both the edge sensing nodes and the central orchestrator hub.
2.  **KiCAD (v7.0+)**: Schematic capture and PCB design suite utilized to lay out helper expansion boards and GPIO routing networks.
3.  **Blender (v3.6+)**: 3D computer graphics software utilized to construct spatial distributions and simulate sensor coverage fields of the Edge-Alert Security Gateway.
4.  **Inkscape (v1.2+)**: Vector graphics software used to draw low-level wiring diagrams and vector architectural maps.

---

### 3.5.4 Mechanical Fabrication and Hardware Assembly

Physical assembly and field preparation require mechanical accessories, connectors, and printing filaments:

1.  **Interface Breakouts & Headers**:
    *   *Adafruit Terminal PiCowbell*: Terminal breakout boards (Product ID: 5904) that route all Pico W pins to spring-loaded screw terminals for solderless field installation.
    *   *2x20-Pin Female Socket Headers (Adafruit Product 5583)*: Soldered onto the PiCowbell boards.
    *   *2x20-Pin Male Short Plug Headers (Adafruit Product 5584)*: Soldered onto the Pico W microcontrollers.
    *   *2x20-Pin Female Short Socket Headers (Adafruit Product 5585)*: For low-profile stacking configurations.
2.  **Assembly & Wiring Materials**:
    *   *Mini Solderless Breadboards*: Used for experimental circuit validation and early sensor testing.
    *   *Jumper Wires*: Multi-gauge male-to-male, male-to-female, and female-to-female jumper wires.
    *   *Soldering Station*: A temperature-controlled iron running lead-free solder for header assembly.
3.  **Enclosure Fabrication**:
    *   *3D Printing Filament*: PLA (Polylactic Acid) or PETG (Polyethylene Terephthalate Glycol) filaments used to extrude snap-fit weather-resistant enclosures. PLA is utilized for general prototyping, while PETG is selected for enclosures requiring higher UV resistance and outdoor structural durability.
