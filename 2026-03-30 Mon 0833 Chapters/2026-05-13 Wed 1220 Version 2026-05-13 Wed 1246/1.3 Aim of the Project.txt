The primary aim of this project is to design, develop, and implement the Modular Adaptive Data Node (MADN), a scalable, decentralized edge-computing framework. This system is designed to harness the latent, idle computational capacity of ubiquitous personal devices in Bulawayo and Tsholotsho. By utilizing a Raspberry Pi 4 Model B as an orchestration hub and Raspberry Pi Pico W units for edge data collection, the project aims to establish a localized, resilient computational network. This framework will dynamically process complex data to provide actionable solutions for agricultural yield optimization, real-time public security surveillance, and resilient commercial point-of-sale operations, effectively bypassing the limitations of centralized cloud infrastructure.
